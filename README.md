# 당당 개인정보처리방침

안드로이드 앱 **당당**(`com.weduls.bloodsugar`)의 개인정보처리방침을 공개하는 저장소입니다.
Google Play Console의 "앱 콘텐츠 → 개인정보처리방침" 항목에는 공개 URL이 필요해서 GitHub Pages로 올립니다.

- 개인정보처리방침: https://weduls.github.io/dandang-privacy/ — [`index.html`](index.html)

계정 삭제 안내 페이지도 있었지만, 데이터 보안 양식에서 "앱에서 계정을 만들 수 없음"으로 신고하면서 필요가 없어져 지웠다(2026-09-21).

## 고칠 때

1. `index.html`을 고친다.
2. 맨 위 "최종 수정일"도 함께 고친다.
3. `main` 브랜치에 push하면 1~2분 뒤 공개 주소에 반영된다.

앱 안에도 같은 문구가 들어간다. 문구를 바꾸면 앱 쪽 문구(`res/values/strings_privacy.xml`)와 설계 문서 부록 A도 같이 맞춘다.
